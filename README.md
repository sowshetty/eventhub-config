# EventHub Configuration Repository

Centralized configuration repository for the EventHub microservices platform.

## Purpose

This repository stores external configuration used by all EventHub microservices.

Configuration is served through Spring Cloud Config Server.

Keeping configuration separate from application source code allows:

- Centralized configuration management
- Environment-specific configuration
- Version control
- Easy rollback
- Independent configuration updates
